# まこの90日ノート

GitHub Pages向けの静的Webアプリです。AI・ログイン・サーバー接続は利用しません。

## 公開
新しい公開リポジトリへ index.html と .nojekyll をアップロードします。Settings → Pages → Deploy from a branch → main / (root) を選んで保存するとURLが発行されます。

個人の記録・知識資料・APIキーは、この公開用フォルダに含めていません。元プロジェクト全体を公開リポジトリへアップロードしないでください。

## 利用
URLを通常のブラウザで開き、設定で名前と開始日を決めます。毎日の記録、内観ノート、気づき、振り返り、90日の取扱説明書を残せます。取り入れたものは項目ごとに名前・量・時間を記録できます。

記録は利用者の端末・ブラウザのlocalStorageに保存します。同じURL・ブラウザで開くと続きを読み込みます。ブラウザのデータ削除やプライベートブラウズでは記録を継続できないことがあります。週に一度、設定から記録をJSONで出力してください。端末を替えるときはJSONを読み込めます。

真子への自動共有はありません。必要な文章や本人が確認した出力ファイルを送ってください。JSONには内観など個人の文章も含みます。

## 初回確認
記録を一件保存し、ページを閉じて同じURLを開き直してください。記録の出力・読み込みも確認してください。スマートフォンでホーム画面に追加する場合は、その後も同じ開き方を使ってください。

公開後のブラウザ実機確認はまだ行っていません。
